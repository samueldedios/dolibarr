# GinecoPlus Module for Dolibarr

## Description

GinecoPlus is a specialized module for Dolibarr designed to provide gynecology management features and patient care workflows.

## Features

- Patient management
- Appointment scheduling
- Medical records
- Treatment tracking
- Billing integration

## Installation

1. Download the module to the modules folder in Dolibarr
2. Enable the module from the admin panel
3. Configure module settings

## Requirements

- Dolibarr >= 15.0
- PHP >= 7.4
